Notes to Grader:
- left clicking(or on mac mouspad click with two fingers) to delete blocks and right clicks to create them
- WASD controls for movement
- There is a yellow cube to show where you are pointing at when you create or delete a box
when it is on a box that already exists it will not appear but you are still facing it
- Game: create a bridge so the capybara can cross the river

Please use a browser that supports "canvas"
